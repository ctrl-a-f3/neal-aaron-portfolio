# Neal Aaron M. Alvarez — Networking / Infrastructure Portfolio

## Open the website

1. Extract the entire ZIP first (do not open the file while it is still inside a ZIP).
2. Open **neal-aaron-portfolio/index.html** in Edge or Chrome.
3. Click **Dashboard**, **About**, **Skills**, or **Certificates** to navigate. The subtle animated red glitch/wipe works in a normal browser. VS Code is **not** required.
4. For optional local-server mode on Windows with Python installed, double-click **start-site.bat**.

### Important

If you still see a scrolling page with an **N.A** logo or a button overlapping **BSIT / THIRD-YEAR UNDERGRADUATE**, you are opening the **older Animated_Portfolio** folder. Open `index.html` from this newly extracted package instead.

This release includes a minimal networking-nodes mark in place of the NA logo, subdued text-selection colors, refined typography, and the single-screen button navigation with a smooth glitch-wipe transition.

The six genuine Cisco Networking Academy course-completion PDFs and local thumbnails are included in **assets/**. Click a certificate to preview or download it.

The animations work without internet or VS Code. Online font loading requires an internet connection, but the site includes system font fallbacks. A reduced-motion system setting disables animations for accessibility. Browser text-selection toolbars (for example, Edge's Copy/Search popup) are browser UI, not part of the site.

## Source files

- `index.html` — page content and navigation
- `styles.css` — design, responsiveness, and animations
- `script.js` — section transitions and certificate viewer
- `assets/images` — profile photo, icon, and certificate thumbnails
- `assets/certificates` — original PDFs
